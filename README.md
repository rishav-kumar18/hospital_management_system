# 🏥 Hospital Management System

---

## 📖 Overview

A web-based application that manages hospital operations digitally. It allows admins, doctors, and patients to handle registration, appointments, and records efficiently.

---

## 🚀 Features

- **Admin:** Manage doctors, patients, and appointments
- **Doctor:** View and update patient information and schedules
- **Patient:** Register, log in, and view assigned doctor and records

---

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript

**Backend:** PHP

**Database:** MySQL

**Server:** Apache / InfinityFree
